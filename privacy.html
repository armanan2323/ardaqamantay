Политика конфиденциальности

Информация о том, как ArdaqAmantay работает с данными посетителей сайта.

1. Общая информация

Сайт ArdaqAmantay предназначен для ознакомления с услугами по пошиву сценических и национальных костюмов и для связи с нами по вопросам заказа.

2. Какие данные мы получаем

При заполнении формы на сайте пользователь может указать своё имя, номер телефона, интересующую категорию костюма и дополнительную информацию о заказе.

3. Для чего используются данные

Указанная информация используется только для связи с пользователем, уточнения деталей заказа и ответа на его запрос.

4. Передача информации

Мы не продаём и не передаём контактные данные пользователей третьим лицам для рекламных рассылок.

5. WhatsApp

После отправки формы данные заявки передаются в WhatsApp для связи с нами. Обработка сообщений в WhatsApp также регулируется правилами и политикой конфиденциальности WhatsApp.

6. Изменения политики

Если порядок работы с данными изменится, информация на этой странице может быть обновлена.
